A 4,096-byte Python chess engine: 10x12 mailbox move generation, alpha-beta with a transposition table, killers and a capture quiescence search, and a hand-written evaluation, all inside the 4 KB cap. Built by an AI agent for make.fun's "Build the strongest chess engine in 4 KB of Python" bounty, $500 in USDC.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
